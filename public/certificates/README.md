# Certificates Folder

Place your certificate files (PDFs, JPGs, or PNGs) in this folder. 

I have configured the website to look for your certificates here. For example, if you save your **AWS S3 Basics** certificate as a PDF here, name it:
`aws-s3-basics.pdf`

And it will be accessible at:
`/certificates/aws-s3-basics.pdf`
